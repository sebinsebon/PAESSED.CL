# Diseño y referencias

Las anotaciones y preferencias son propuestas de diseño; no acreditan una interfaz implementada.

## Proposito

Documentar criterios visuales y de experiencia para que el producto sea claro, educativo y motivante.

## Direccion actual

- Estetica simple.
- Inspiracion tipo Duolingo para la ruta de [[producto/APRENDER]].
- Tailwind como referencia de implementacion visual.
- Botones redondeados.
- Sensacion gamificada.
- Claridad por sobre decoracion.
- Uso educativo primero.
- Componentes consistentes.

## Principios

La gamificacion debe ayudar a estudiar, no distraer. El usuario debe saber siempre que hacer ahora, que esta mejorando y que necesita reforzar.

Inicio debe sentirse como un centro de control. Aprender debe sentirse como ruta guiada. Playground debe sentirse flexible y rapido. Verificador debe sentirse analitico y claro.

## No hacer por ahora

- No copiar literalmente Duolingo.
- No definir un sistema visual exhaustivo todavia.
- No agregar complejidad visual antes de cerrar flujos.

## Preguntas abiertas

- Que tono visual es mejor para estudiantes PAES: mas ludico, mas academico o mixto?
- Que elementos gamificados realmente aumentan constancia?
- Como mostrar debilidades sin desmotivar?
- Como disenar puntaje estimado sin ansiedad innecesaria?
