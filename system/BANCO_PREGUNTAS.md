# Banco de Preguntas

## Proposito

Documentar la idea de tener preguntas oficiales DEMRE clasificadas para alimentar Aprender, Playground, estadisticas y posibles diagnosticos.

## Clasificacion esperada

Cada pregunta podria clasificarse por:

- ano;
- prueba;
- numero;
- eje;
- tema;
- habilidad;
- dificultad;
- respuesta;
- explicacion;
- assets.

## Contenido

La prioridad es usar contenido oficial DEMRE cuando corresponda. No se debe descargar ni recopilar contenido todavia en esta etapa de documentacion.

## Relacion con producto

- [[../product/APRENDER]] usa el banco para lecciones, practica y diagnostico.
- [[../product/PLAYGROUND]] usa el banco para practica libre filtrada.
- [[ESTADISTICAS]] puede usar metadatos del banco para calcular rendimiento por eje, tema y habilidad.

## Por definir

- Fuente exacta de preguntas oficiales.
- Formato final de almacenamiento.
- Taxonomia de ejes, temas y habilidades.
- Nivel de dificultad.
- Formato de assets.
- Politica para preguntas repetidas.
