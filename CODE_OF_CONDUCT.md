# Code of Conduct

PAESSED busca ser un proyecto abierto, respetuoso y util para estudiantes.

Esperamos que quienes participen:

- Traten a otras personas con respeto.
- Den feedback especifico y accionable.
- Eviten ataques personales, burlas o comentarios discriminatorios.
- Sean cuidadosos con estudiantes, datos personales y contenido educativo.
- Acepten correcciones cuando algo pueda causar dano o confusion.

No se aceptan:

- Acoso, insultos o intimidacion.
- Publicacion de datos privados.
- Material protegido subido sin permiso.
- Conductas que busquen confundir, sabotear o abusar del proyecto.

Si ves un problema de conducta, abre un issue privado si existe esa opcion o contacta
a las personas mantenedoras del proyecto por el canal indicado en GitHub.
